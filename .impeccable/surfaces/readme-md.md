## Scope

GitHub profile README (github.com/klaygomes). Visitor mode: Persuade. Audience: recruiters and hiring managers first, engineers second. Action: contact (email, LinkedIn) or open a project.

## Direction contract

THESIS: The profile is one logic-analyzer capture of Cleiton's stack. Channels run from the screen (React) down to the STM32 clock, and decoded-packet labels carry the facts. It refuses the GitHub profile default of badge walls, typing animations and stats cards.

OWN-WORLD: An analyzer capture window: cool gray instrument ground (never cream), dotted time divisions, graphite square-wave traces, decoded packets as pointed-end frames. One signal colour only, amber, owned by the clock channel and the single highlighted packet per channel. One typeface, Archivo, with hierarchy from its width axis: condensed caps for channel labels, expanded heavy for the name. Square corners, hairline rules, no shadows. Light and dark variants.

STORY: The visitor reads name, role and range in one capture, sees each layer of the stack as a live channel, then opens a project lane or a contact packet.

FIRST VIEWPORT: 880-wide capture. Header strip: name large left, role under it, cursor readout right measuring "20+ years". Five channels below, top to bottom: screen, Node.js, UNIX, C, STM32 clock (amber). Contact packets as linked badges directly under the capture.

FORM: logic analyzer timing capture, position 6 of 7 on the grounded list, seed d207db04. Raises: one signal colour (from the drawcord cape), quiet idle lines (from ikebana ma), label size by importance (from telop), one highlighted packet per channel (from the zine), one typeface everywhere (from the phosphor terminal).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
